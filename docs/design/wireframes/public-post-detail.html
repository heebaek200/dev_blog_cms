JPA Auditing으로 작성 시각을 일관되게 관리하기

#JPA#SpringBoot

여러 엔티티가 공통으로 사용하는 생성 시각과 수정 시각은 반복해서 직접 갱신하기보다 하나의 정책으로 관리하는 편이 안전합니다.

공통 엔티티 구성

@CreatedDate와 @LastModifiedDate를 공통 엔티티에 선언하고 JPA Auditing을 활성화합니다.

@CreatedDate
private LocalDateTime createdAt;

@LastModifiedDate
private LocalDateTime updatedAt;

이 프로젝트는 최초 관리자와 게시글, 카테고리, 태그에 같은 규칙을 적용합니다.
